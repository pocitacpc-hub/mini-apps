# Mini Apps

[Otevřít rozcestník](https://pocitacpc-hub.github.io/mini-apps/)

## Instalace na telefon

- Android v Chromu – otevřete rozcestník, v nabídce vyberte instalaci aplikace a potvrďte.
- iPhone v Safari – otevřete rozcestník, zvolte Sdílet, Přidat na plochu a zapněte Otevřít jako webovou aplikaci.

Po prvním načtení s internetem funguje rozcestník, kalkulačka i obě prezentace offline. Kalkulačka při nedostupnosti knihovny SheetJS exportuje data jako CSV.

## Údržba

Rozcestník načítá seznam z apps/apps.json. Při přidání stránky doplňte její lokální soubory do seznamu v sw.js a zvyšte verzi cache. Pro ověření používejte lokální HTTP server nebo GitHub Pages.
